# Session Log - 2026-04-16 / 01

## Goal

Repair the WSP Everyday Companion parser, add safe rebuild tooling for the corrupted
2020-2026 EC setlist window, and verify the parser against real EC examples before
reviewing rebuilt rows.

## Findings

- The current primary parser in
  `src/jambandnerd/data_collection/wsp/parser.py` was splitting comma-titled songs
  into multiple rows because it tokenized setlists with a naive `split(",")`.
- Live repro against
  `https://www.everydaycompanion.com/setlists/20200124a.asp` returned
  `Lawyers`, `Guns`, and `And Money` as separate songs instead of
  `Lawyers, Guns, And Money`.
- Because the broken parser still returned non-empty output, the collector never
  reached the safer HTML-table fallback path.
- `panicstats` now has an EC adapter/parser implementation that uses protected
  comma-title handling and structured table parsing. That logic was used as a
  reference only and ported locally into JamBandNerd.

## Files Changed

- `src/jambandnerd/data_collection/wsp/parser.py`
  - Replaced the naive line-splitting parser with a structured EC parser that:
    - supports table-style EC pages and legacy paragraph pages
    - protects known comma-titled songs before tokenization
    - normalizes set labels more deliberately
    - extracts song notes where available
  - Added `parsed_output_has_fragmented_comma_titles()` to detect the old
    corruption pattern.
- `src/jambandnerd/data_collection/wsp/collector.py`
  - Added a sanity gate: if the primary parser returns fragmented comma-title
    output, the collector logs a warning and falls back to HTML-table parsing.
- `tests/data_collection/wsp/test_wsp_html_parsing.py`
  - Added regression coverage for:
    - preserving `Lawyers, Guns, And Money` as one song
    - forcing collector fallback when the primary parser returns fragmented
      comma-title output
- `tests/data_collection/wsp/fixtures/setlist_page_with_comma_title.html`
- `tests/data_collection/wsp/fixtures/setlist_table_rows_with_comma_title.html`
- `scripts/admin/repair_wsp_setlists_range.py`
  - New WSP-only repair utility that deletes `wsp_setlists_raw` rows for a date
    range while preserving `wsp_shows_raw` rows and `show_id` values.
- `scripts/README.md`
  - Documented the new admin repair script.
