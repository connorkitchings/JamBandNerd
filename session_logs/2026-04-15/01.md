## Findings

Two distinct failure modes:

1. **Migration ordering conflict** — `20260413_drop_legacy_tables.sql` contained `DROP TABLE IF EXISTS public.predictions CASCADE` meant for an old football-era table, but it now destroys the unified `predictions` table created moments earlier by `20260413_consoldiate_predictions_table.sql` (alphabetical execution: `consoldiate` < `drop_legacy`). All 5 non-WSP bands failed with `relation "public.predictions" does not exist`.

2. **Fantasy Goose post-submit race condition** — After `form.requestSubmit()` + `domcontentloaded`, the code immediately fetched My Picks with zero delay. The server had not committed the entry yet, and a single failed string-match caused a hard `RuntimeError`.

## Changes Made

### Migration fix

- `supabase/migrations/20260413_drop_legacy_tables.sql`: Removed `DROP TABLE IF EXISTS public.predictions CASCADE` line.

### Fantasy Goose hardening

- `src/jambandnerd/integrations/fantasy_goose.py`:
  - Added 500ms pause after Alpine.js show-select `change` event for reactivity.
  - Changed post-submit wait from `domcontentloaded` to `networkidle`.
  - Replaced single My Picks check with 3-attempt retry loop at 2s intervals.
  - Added diagnostic logging (post-submit URL, post-submit body, My Picks body) on failure.
  - Extracted `FANTASY_GOOSE_VERIFICATION_RETRIES` and `FANTASY_GOOSE_VERIFICATION_DELAY_MS` constants.
- `tests/test_fantasy_goose.py`: Added 4 new tests for verification constants and `has_existing_entry` edge cases.
