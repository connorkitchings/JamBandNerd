# Session Log — 2026-11-21 (01)

## Goal

- Investigate and fix the failed GitHub Actions `Daily Data Pipeline` run from 2026-11-21 (`44844362362`).

## Constraints

- Work on a feature branch (`fix/pipeline-eastern-show-date`), never directly on `main`.
- Keep show-date boundaries consistent with US local concert dates (US Eastern time) while keeping UTC timestamps for age/freshness calculations.
- Update workflow docs and add targeted unit tests.

## Root Cause

- Over six consecutive days (2026-11-15 through 2026-11-21), GitHub Actions delayed the `0 19 * * *` (19:00 UTC) scheduled `Daily Data Pipeline` by 4–7 hours, starting runs between `00:31Z` and `02:12Z` (7:31–9:12 PM EST).
- Pipeline show-date boundary helpers (`completed_show_window`, `collection_preflight`, `generate_live_predictions`, `validate_prediction_tables`, `generate_pipeline_summary`, `run_backtest`, plus WSP/Billy collectors) defaulted to host `date.today()` (UTC on GitHub Actions runners).
- After `00:00 UTC`, `date.today()` advanced to tomorrow relative to US Eastern time, causing `verify_data_freshness.py` to treat that evening's in-progress/upcoming US show as a completed show:
  - 2026-11-19T00:51Z (Nov 18 7:51 PM EST): Goose `2026-11-18` (ID `1780327778`) flagged partial (2 songs) -> degraded (age 23.4h).
  - 2026-11-20T00:58Z (Nov 19 7:58 PM EST): Goose `2026-11-19` (ID `1780327779`) flagged partial (2 songs) -> degraded (age 47.5h).
  - 2026-11-21T00:31Z (Nov 20 7:31 PM EST): Goose `2026-11-20` (ID `1780327780`) flagged partial (1 song) -> degraded reuse exceeded 48h window (age 71.1h) -> hard failure. Billy `2026-11-20` (ID `31800`) was also falsely degraded.

## Fix

- Added `src/jambandnerd/utils/dates.py` with `SHOW_DATE_TIMEZONE = ZoneInfo("America/New_York")` and `current_show_date()` as the single source of truth for US Eastern calendar dates.
- Switched show-date boundary defaults from `date.today()` to `current_show_date()` across `scripts/common.py`, `scripts/collection_preflight.py`, `scripts/generate_live_predictions.py`, `scripts/validate_prediction_tables.py`, `scripts/generate_pipeline_summary.py`, `scripts/run_backtest.py`, `src/jambandnerd/data_collection/wsp/orchestration.py`, and `src/jambandnerd/data_collection/billy/collector.py`.
- Shifted `.github/workflows/daily-pipeline.yml` schedule from `0 19 * * *` to `23 18 * * *` (off `:00` top-of-hour queue congestion and 37 minutes earlier) and updated `docs/operations/github_actions.md`.
- Added unit tests in `tests/test_data_diagnostics_scripts.py` covering UTC-midnight crossover behavior for `current_show_date()` and `completed_show_window()`.
