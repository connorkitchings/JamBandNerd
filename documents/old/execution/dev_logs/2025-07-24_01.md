## Blockers

- **Database Schema Constraint Override:** Despite explicit string type enforcement in pandas
  (`astype('object')`), Supabase date/timestamp columns automatically convert MM/DD/YYYY strings
  to YYYY-MM-DD format.
- **Mixed Date Format Status:** `phish_songs.debut_date` stores correctly as MM/DD/YYYY (likely
  text column), but `phish_shows.showdate` converts to YYYY-MM-DD (date/timestamp column).
- **Schema Migration Required:** To achieve consistent MM/DD/YYYY string storage, database schema
  migration is required to change date columns from date/timestamp types to text/varchar types.
