## Blockers Encountered

## New Learnings/Patterns

- **Pattern:** Centralizing all scraping logic into a single `loaders.py` per band dramatically
  improves maintainability and reduces code duplication.
- **Pattern:** Integrating caching and update logic directly into the DataCollector class provides a
  clean, extensible architecture for all future band modules.
- **Solution:** Using `ThreadPoolExecutor` with robust error handling and progress bars (`tqdm`) is
  effective for concurrent web scraping in data pipelines.
