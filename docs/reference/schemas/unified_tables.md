# Unified Table Schemas

This page documents all prediction and accuracy table layouts used by the
JamBandNerd pipeline.

> **Branch note (`feat/single-model-per-band`):** The active backend write
> boundary on this branch is the `setlist_*` table family (see
> [Setlist Tables (Phase A)](#setlist-tables-phase-a) below and
> [ADR 0001](../../contributor/adr/0001-single-model-per-band.md)).
> Legacy tables listed below remain populated by `main`/`dev` and continue
> serving the live website until the frontend cutover completes. They are
> read-only from the perspective of Phase A backend code.

## Legacy Tables (read-only on this branch)

### Prediction Tables

Current prediction tables:

- `predictions`
- `prediction_songs` (derived)
- `historical_prediction_runs` (historical scored-run lineage)

```sql
CREATE TABLE public.predictions (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_slug text NOT NULL,
    reference_date date NOT NULL,
    predictions jsonb NOT NULL,
    top_k integer NOT NULL,
    model_version text NOT NULL,
    collected_at timestamp with time zone NULL,
    predicted_at timestamp with time zone NOT NULL DEFAULT now(),
    CONSTRAINT predictions_pkey PRIMARY KEY (id),
    CONSTRAINT ux_predictions_band_slug_ref_version
        UNIQUE (band, model_slug, reference_date, model_version)
);
```

Notes:

- `predictions` is a ranked JSON array.
- JSON entry fields differ by model.
- the current design stores one row per
  `(band, model_slug, reference_date, model_version)`
  as the canonical write boundary.

### Per-Song Prediction Projection

```sql
CREATE TABLE public.prediction_songs (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_slug text NOT NULL,
    model_version text NOT NULL,
    reference_date date NOT NULL,
    predicted_at timestamp with time zone NOT NULL,
    rank integer NOT NULL,
    song_name text NOT NULL,
    top_k integer NOT NULL,
    prediction_payload jsonb NOT NULL,
    CONSTRAINT prediction_songs_pkey PRIMARY KEY (id),
    CONSTRAINT prediction_songs_band_slug_version_date_rank_key
        UNIQUE (band, model_slug, model_version, reference_date, rank)
);
```

Notes:

- `prediction_songs` is derived from `predictions`, not written as an
  independent source of truth.
- `prediction_payload` stores the exact model-specific JSON object for that
  ranked song.

### Historical Scored Runs

```sql
CREATE TABLE public.historical_prediction_runs (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_slug text NOT NULL,
    model_version text NOT NULL,
    run_type text NOT NULL DEFAULT 'backtest',
    reference_date date NOT NULL,
    target_show_id text NOT NULL,
    target_show_date date NOT NULL,
    generated_at timestamp with time zone NOT NULL,
    actual_songs jsonb NOT NULL,
    actual_song_count integer NOT NULL,
    top_k integer NOT NULL,
    predictions jsonb NOT NULL,
    CONSTRAINT historical_prediction_runs_pkey PRIMARY KEY (id),
    CONSTRAINT historical_prediction_runs_context_key
        UNIQUE (band, model_slug, model_version, reference_date, target_show_id)
);
```

Notes:

- this is the canonical lineage store for scored historical prediction boards
- `predictions` preserves the exact ranked JSON payload emitted by the model
- `actual_songs` preserves the setlist snapshot used when the row was scored

## Per-Show Accuracy Table

```sql
CREATE TABLE public.accuracy_per_show (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_version text NOT NULL,
    show_id text NOT NULL,
    show_date date NOT NULL,
    prediction_run_id bigint NULL,
    actual_song_count integer NOT NULL,
    k10_hit integer NULL,
    k10_matches integer NULL,
    k10_precision double precision NULL,
    k10_recall double precision NULL,
    k10_f1 double precision NULL,
    k25_hit integer NULL,
    k25_matches integer NULL,
    k25_precision double precision NULL,
    k25_recall double precision NULL,
    k25_f1 double precision NULL,
    k50_hit integer NULL,
    k50_matches integer NULL,
    k50_precision double precision NULL,
    k50_recall double precision NULL,
    k50_f1 double precision NULL,
    evaluated_at timestamp with time zone NOT NULL,
    CONSTRAINT accuracy_per_show_pkey PRIMARY KEY (id),
    CONSTRAINT accuracy_per_show_band_model_version_show_id_key
        UNIQUE (band, model_version, show_id)
);
```

Notes:

- `accuracy_per_show` is the canonical historical evaluation store.
- `prediction_run_id` links new backtest rows to `historical_prediction_runs`.
- aggregate summary tables are no longer part of the active write contract.

## Setlist Tables (Phase A)

> These four tables are the active backend write boundary on
> `feat/single-model-per-band`. They are created by
> `supabase/migrations/20260425_create_setlist_tables.sql`.

Key differences from legacy tables:

- `model_slug` is **removed**. There is one model per band.
- `model_version` is **retained** as the freshness and iteration signal.
- Unique keys are `(band, model_version, target_show_key)`.

```sql
CREATE TABLE public.setlist_predictions (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    target_show_key text NOT NULL,
    target_show_date date NOT NULL,
    reference_date date NOT NULL,
    model_version text NOT NULL,
    generated_at timestamp with time zone NOT NULL,
    top_k integer NOT NULL,
    predictions jsonb NOT NULL,
    CONSTRAINT setlist_predictions_pkey PRIMARY KEY (id),
    CONSTRAINT setlist_predictions_band_version_show_key
        UNIQUE (band, model_version, target_show_key)
);
```

```sql
CREATE TABLE public.setlist_prediction_songs (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    target_show_key text NOT NULL,
    model_version text NOT NULL,
    prediction_run_id bigint NOT NULL,
    rank integer NOT NULL,
    song_name text NOT NULL,
    score double precision NULL,
    prediction_payload jsonb NOT NULL,
    CONSTRAINT setlist_prediction_songs_pkey PRIMARY KEY (id),
    CONSTRAINT setlist_prediction_songs_band_version_show_rank_key
        UNIQUE (band, model_version, target_show_key, rank)
);
```

```sql
CREATE TABLE public.setlist_results (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    target_show_key text NOT NULL,
    target_show_date date NOT NULL,
    reference_date date NOT NULL,
    model_version text NOT NULL,
    generated_at timestamp with time zone NOT NULL,
    top_k integer NOT NULL,
    predictions jsonb NOT NULL,
    actual_songs jsonb NOT NULL,
    actual_song_count integer NOT NULL,
    CONSTRAINT setlist_results_pkey PRIMARY KEY (id),
    CONSTRAINT setlist_results_band_version_show_key
        UNIQUE (band, model_version, target_show_key)
);
```

```sql
CREATE TABLE public.setlist_accuracy (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_version text NOT NULL,
    show_id text NOT NULL,
    target_show_key text NOT NULL,
    show_date date NOT NULL,
    reference_date date NOT NULL,
    prediction_run_id bigint NULL,
    actual_song_count integer NOT NULL,
    p10 double precision NULL,
    p25 double precision NULL,
    p50 double precision NULL,
    recall_10 double precision NULL,
    recall_25 double precision NULL,
    recall_50 double precision NULL,
    weighted_precision_score double precision NULL,
    evaluated_at timestamp with time zone NOT NULL,
    CONSTRAINT setlist_accuracy_pkey PRIMARY KEY (id),
    CONSTRAINT setlist_accuracy_band_version_show_key
        UNIQUE (band, model_version, target_show_key)
);
```

Notes:

- `setlist_predictions` and `setlist_prediction_songs` replace
  `next_show_prediction_runs` and `next_show_prediction_songs`.
- `setlist_results` and `setlist_accuracy` replace
  `completed_show_prediction_runs` and `completed_show_accuracy`.
- `weighted_precision_score` is the secondary metric:
  `0.2 × p10 + 0.7 × p25 + 0.1 × p50` (see `WEIGHTED_PRECISION_WEIGHTS` in
  `src/jambandnerd/config/models.py`).
- All four tables require RLS with `SELECT` for `anon`/`authenticated`,
  writes restricted to `service_role`.
