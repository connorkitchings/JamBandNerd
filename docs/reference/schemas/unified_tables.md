# Unified Table Schemas

This document provides the canonical `CREATE TABLE` statements for the unified prediction and accuracy tables. These schemas are the source of truth and reflect the data structures used by the pipeline scripts.

---

## Predictions Tables

Prediction tables store the top-K predictions for a given band, model, and reference date. A single row contains metadata and a JSONB array of the predictions.

- **Table Name**: `predictions_{model_slug}` (e.g., `predictions_notebook`, `predictions_ckplus`)

### `predictions_notebook` / `predictions_ckplus`

```sql
CREATE TABLE public.predictions_ckplus (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NULL,
    reference_date date NULL,
    predictions jsonb NULL,
    top_k integer NULL,
    model_version text NULL,
    predicted_at timestamp with time zone NULL,
    CONSTRAINT predictions_ckplus_pkey PRIMARY KEY (id),
    CONSTRAINT predictions_ckplus_band_reference_date_model_version_key UNIQUE (band, reference_date, model_version)
);
```

**Notes:**

- The `predictions` column contains a JSON array where each object has fields specific to the model (e.g., `plays_past_year` for notebook, `ckplus_score` for ckplus).
- The unique constraint ensures that only one set of predictions exists for a given band, date, and model version.

## Accuracy Tables

### Aggregate Accuracy Table

This table stores the aggregate performance metrics for a model over a rolling window of the last N completed shows.

- **Table Name**: `accuracy_{model_slug}` (e.g., `accuracy_notebook`, `accuracy_ckplus`)

```sql
CREATE TABLE public.accuracy_ckplus (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NULL,
    model_version text NULL,
    window_start date NULL,
    window_end date NULL,
    num_shows integer NULL,
    evaluated_at timestamp with time zone NULL, -- Correct timestamp column
    k10_hit_rate double precision NULL,
    k10_avg_matches double precision NULL,
    k10_precision double precision NULL,
    k10_recall double precision NULL,
    k10_f1 double precision NULL,
    k25_hit_rate double precision NULL,
    k25_avg_matches double precision NULL,
    k25_precision double precision NULL,
    k25_recall double precision NULL,
    k25_f1 double precision NULL,
    k50_hit_rate double precision NULL,
    k50_avg_matches double precision NULL,
    k50_precision double precision NULL,
    k50_recall double precision NULL,
    k50_f1 double precision NULL,
    CONSTRAINT accuracy_ckplus_pkey PRIMARY KEY (id),
    CONSTRAINT accuracy_ckplus_band_model_version_window_start_window_end_key UNIQUE (band, model_version, window_start, window_end)
);
```

### Per-Show Accuracy Table

This table stores the historical accuracy metrics for every individual show, enabling trend analysis.

- **Table Name**: `accuracy_per_show`

```sql
CREATE TABLE public.accuracy_per_show (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_version text NOT NULL,
    show_id bigint NOT NULL,
    show_date date NOT NULL,
    actual_song_count integer NOT NULL,
    k10_hit integer NULL,
    k10_matches integer NULL,
    k10_precision double precision NULL,
    k10_recall double precision NULL,
    k10_f1 double precision NULL,
    k25_hit integer NULL,
    k25_matches integer NULL,
    k25_precision double precision NULL,
    k25_recall double precision NULL,
    k25_f1 double precision NULL,
    k50_hit integer NULL,
    k50_matches integer NULL,
    k50_precision double precision NULL,
    k50_recall double precision NULL,
    k50_f1 double precision NULL,
    evaluated_at timestamp with time zone NOT NULL,
    CONSTRAINT accuracy_per_show_pkey PRIMARY KEY (id),
    CONSTRAINT accuracy_per_show_band_model_version_show_id_key UNIQUE (band, model_version, show_id)
);
```
