# Deal Model Table Schemas

This document provides the SQL statements to create the Deal model prediction and accuracy tables in Supabase.

## Predictions Table

```sql
CREATE TABLE public.predictions_deal (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NULL,
    reference_date date NULL,
    predictions jsonb NULL,
    top_k integer NULL,
    model_version text NULL,
    predicted_at timestamp with time zone NULL,
    CONSTRAINT predictions_deal_pkey PRIMARY KEY (id),
    CONSTRAINT predictions_deal_band_reference_date_model_version_key
        UNIQUE (band, reference_date, model_version)
);
```

## Accuracy Table

```sql
CREATE TABLE public.accuracy_deal (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NOT NULL,
    model_version text NOT NULL,
    window_start date NOT NULL,
    window_end date NOT NULL,
    k_value integer NOT NULL,
    hit_rate real,
    avg_matches real,
    precision_score real,
    recall_score real,
    f1_score real,
    auc real,
    CONSTRAINT accuracy_deal_pkey PRIMARY KEY (id),
    CONSTRAINT accuracy_deal_band_model_version_window_key
        UNIQUE (band, model_version, window_start, window_end, k_value)
);
```

## Usage

Run these statements against your Supabase project:

```bash
# Using psql
psql -h your-project.supabase.co -U postgres -d postgres -f deal_tables.sql

# Or via Supabase SQL editor
```

Note: Grant appropriate permissions to the service_role and anon users as needed.
