# Deal Model Table Schemas

This document provides the SQL statements to create the Deal model prediction and
aggregate accuracy tables in Supabase.

## Predictions Table

```sql
CREATE TABLE public.predictions_deal (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NULL,
    reference_date date NULL,
    predictions jsonb NULL,
    top_k integer NULL,
    model_version text NULL,
    predicted_at timestamp with time zone NULL,
    CONSTRAINT predictions_deal_pkey PRIMARY KEY (id),
    CONSTRAINT predictions_deal_band_reference_date_model_version_key
        UNIQUE (band, reference_date, model_version)
);
```

## Accuracy Table

```sql
CREATE TABLE public.accuracy_deal (
    id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
    created_at timestamp with time zone NOT NULL DEFAULT now(),
    band text NULL,
    model_version text NULL,
    window_start date NULL,
    window_end date NULL,
    num_shows integer NULL,
    evaluated_at timestamp with time zone NULL,
    k10_hit_rate double precision NULL,
    k10_avg_matches double precision NULL,
    k10_precision double precision NULL,
    k10_recall double precision NULL,
    k10_f1 double precision NULL,
    k25_hit_rate double precision NULL,
    k25_avg_matches double precision NULL,
    k25_precision double precision NULL,
    k25_recall double precision NULL,
    k25_f1 double precision NULL,
    k50_hit_rate double precision NULL,
    k50_avg_matches double precision NULL,
    k50_precision double precision NULL,
    k50_recall double precision NULL,
    k50_f1 double precision NULL,
    CONSTRAINT accuracy_deal_pkey PRIMARY KEY (id),
    CONSTRAINT accuracy_deal_band_model_version_window_start_window_end_key
        UNIQUE (band, model_version, window_start, window_end)
);
```

`accuracy_deal` now matches the unified aggregate accuracy contract used by
`scripts/save_aggregate_accuracy.py`. Older narrow rows keyed by `k_value`
should be migrated through the Supabase migration history rather than written
directly.

## Usage

Run these statements against your Supabase project:

```bash
# Using psql
psql -h your-project.supabase.co -U postgres -d postgres -f deal_tables.sql

# Or via Supabase SQL editor
```

Note: Grant appropriate permissions to the service_role and anon users as needed.
